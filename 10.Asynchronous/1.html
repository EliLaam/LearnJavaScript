Khái niệm không đồng bộ (Asynchronous)

Luồng không đồng bộ JavaScript đề cập đến cách JavaScript xử lý các tác vụ cần thời gian để hoàn tất, giống như đọc tệp hoặc chờ người dùng nhập, mà không chặn việc thực thi mã khác.

Việc "đi ra ngoài Internet" để lấy dữ liệu là một việc RẤT TỐN THỜI GIAN (có thể mất vài mili giây đến vài giây). Nếu JavaScript phải "đứng im chờ đợi" cho đến khi có dữ liệu trả về, toàn bộ trang web của bạn sẽ bị "đóng băng", người dùng không thể làm gì được.

Giải pháp: JavaScript thực hiện các tác vụ này một cách bất đồng bộ (asynchronously).

    Nó sẽ:
  1. Gửi yêu cầu đi.
  2. KHÔNG CHỜ ĐỢI. Nó tiếp tục chạy các dòng code tiếp theo ngay lập tức.
  3. Khi nào yêu cầu hoàn thành (thành công hoặc thất bại), nó sẽ thực thi một "hàm đợi sẵn" để xử lý kết quả.

Có 3 cơ chế chính

  • CallBack
  • Promise
  • async/await

Các Khái Niệm Quan Trọng Khác

CallStack

Call Stack: Cấu trúc dữ liệu đơn giản được cung cấp bởi V8 Engine JavaScript thực thi mã bằng cách sử dụng Call Stack, theo dõi hàm hiện đang thực thi.

  • Hàm chính (toàn bộ tập lệnh) được tự động thêm vào ngăn xếp cuộc gọi.
  • Các hàm được thêm vào ngăn xếp lệnh gọi khi được gọi và xóa sau khi thực thi.
  • JavaScript là một luồng, có nghĩa là chỉ một tác vụ được xử lý trong ngăn xếp lệnh gọi tại một thời điểm.

CallBack Queue

Công việc của nó là duy trì một danh sách tất cả các hàm gọi lại cần được thực thi.

Event Loop

Vòng lặp sự kiện liên tục kiểm tra xem ngăn xếp cuộc gọi có trống hay không.

Sau đó, nó xử lý các tác vụ từ Callback Queue hoặc Microtask Queue (như gọi lại Promise).

Web API

What is Web API? API stands for Application Programming Interface.

A Web API is an application programming interface for the Web.

A Browser API can extend the functionality of a web browser.

A Server API can extend the functionality of a web server.
